## Getting started (after Milestone 0)
Requires Node 22+, pnpm (`corepack enable`), Supabase CLI, EAS CLI, and Claude Code.
```
pnpm install
supabase start
pnpm dev
```
Open the folder in Claude Code and run `/feature "<idea>"`.
